# ClearSight Frontend Scanner & Printer Configuration
**Version:** v1.0

## Barcode Scanner Setup
- Use USB HID-compatible barcode scanners
- No driver required; acts as keyboard input
- Focus cursor on serial number input field before scanning

## Printer Setup
- Use label printer with browser-supported drivers
- Configure page size in browser print settings (e.g., 50mm x 30mm)
- Include SKU, serial, and stage info in print layout

## Troubleshooting
- Scanner not detected: check USB port & power
- Printer misaligned: adjust margins in browser print dialog

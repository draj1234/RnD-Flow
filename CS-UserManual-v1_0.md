# ClearSight User Manual (v1.0)

## 1. Introduction
ClearSight is an internal, web-based production traceability system designed to manage, track, and ensure accountability across multiple stages of the production process. This manual provides feature descriptions, usage instructions, and reference material for operators, QC staff, floor managers, and support teams.

---

## 2. System Overview
ClearSight tracks every board from the moment it enters the production process. Each board is assigned:
- **Unique Serial Number (auto-generated)**
- **SKU & ERP Linkage**
- **Full lifecycle tracking** from soldering → QC → electrical testing → final assembly

**Key Features:**
1. **Stage-wise Tracking:** Know exactly which stage a board is in at any time.
2. **Accountability Logs:** Who handled the board, when, and what actions were taken.
3. **Rework Routing:** Boards failing QC or testing are redirected for fixes and re-tested.
4. **Multi-product Handling:** Supports multiple SKUs with ERP integration.
5. **Dashboards & Alerts:** Real-time data for floor managers.

## 4. Common Workflows

### 4.1 Starting a New Board
1. Scan or manually enter SKU.
2. ClearSight generates a **Unique Serial Number**.
3. Board is assigned to the **Soldering Station**.

### 4.2 Moving a Board to the Next Stage
1. Operator scans serial number.
2. Selects “Move to Next Stage” in dashboard.
3. System records timestamp and operator ID.

### 4.3 Rework Handling
1. If QC or electrical test fails, operator marks board for rework.
2. Board is redirected to soldering station.
3. After fix, board can bypass QC (if permitted) or return to QC before final testing.

## 6. Permissions & Roles
- **Operator:** Can scan, update stage, mark rework.
- **QC Tester:** Can pass/fail boards, view details.
- **Electrical Tester:** Can pass/fail boards, run tests.
- **Floor Manager:** Full dashboard view, reporting tools, rework approvals.

---

## 7. Terminology & Acronyms
- **SKU** – Stock Keeping Unit
- **ERP** – Enterprise Resource Planning system
- **QC** – Quality Control
- **Serial Number** – Unique identifier for each board generated by ClearSight
- **Stage** – A specific step in the production process
- **Rework** – Process of fixing a failed board
